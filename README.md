# 🌍 Global Cyber Threat Intelligence Dashboard

An interactive cybersecurity dashboard that visualizes real-world public threat intelligence feeds on a live geolocated global map.

Built using Python, Streamlit, Plotly, and public cyber threat feeds including Feodo Tracker and Spamhaus DROP.

---

## Features

- 🌎 Real-time geolocated threat visualization
- 🚨 Severity classification system
- 🔍 Interactive filtering by:
  - source
  - malware family
  - status
  - port
  - severity
- 📊 Threat intelligence analytics charts
- 🛰️ Live public threat intelligence feeds
- 🔄 Automatic dashboard refresh
- 🎯 Simulated target attack mapping

---

## Tech Stack

- Python
- Streamlit
- Plotly
- Pandas
- Requests

---

## Threat Intelligence Sources

- Feodo Tracker
- Spamhaus DROP List
- IP-API Geolocation

```bash
pip install -r requirements.txt
streamlit run app.py
```
